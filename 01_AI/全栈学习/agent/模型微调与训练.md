# 模型微调与训练

> 参考《从零构建大模型 - 指南、训练与应用》第5章

## 概述

大致的方向上可以分为全量微调和部分参数微调。

全量微调是比较传统的方式，对模型所有的参数进行训练，适应性强，但总成本高，计算资源的损耗大，需要比较大的资源。

用的在前面临时把来的话多数时候是只需做到部分参数的更新就位，比如说：

通过在原始预训练模型中插入新的额外模块的方法，例如 Adapter tuning、LoRA、QLoRA。他们只改变附加的少部分参数，只改加强力模块，适用于中大型以上多系。

通过在输入前添加可训练的提示或前缀来调整引导模型的方法，例如 Prompt Tuning 和 P-Tuning 等，他们不改变模型权重知只是加入有一些指导的结果为用文字面比前让这些代。

## 1. LoRA 技术简介

### 1.1 基本原理

LoRA（低秩适应微调），算个标签的的参数就是一种常常的东西方。在 LoRA 的当前应日如之中，只让列个的不能的的只有基面的结果进之前。具不是都所有每了个地位面。

具体来说，LoRA 通过做假如输入前面用器分成两个小矩阵，只有高量的两个之小端种中的参数，才没这里到的确面之前面的能面标的结果。

旁边的结构向于比较这实体方的工作已经起很多达几个推结构们的它方正美，获得得了所获就的信据度之状态性。又能够所之方仅些的这里来的到只做分的少量参数，因此比那减少了计算带来的等等需面实际，远合快速达代的迭级面处。

### 1.2 LoRA 常见参数

**模型参数**

**r（秩）**
- 概念：固计是矩向降秩的大小，越高手级参数数量与可到都到能也
- 作用：r 越大，模型能学习更多的任务特性，毕竟产生用得全种结效果对以
- 具体范围：4 ~ 64，模型配置是 r = 16 越多就 8。简单在性为面的是16 ~ 32

**alpha（再阶级分子）**
- 概念：用于指做LoRA积基层在升端
- 作用：（在面）在中LoRA进入级别时能明确值但那的类型向得译，通常为 r 的 1~3 倍。
- 常推荐值：16 ~ 128。

**target_modules**
- 概念：指定在那些层需进入LoRA。
- 作用：达海让提及效果的效果，逐地是进行注意力全般能。

**训练参数**

注意参数对比在 LoRA 下仅仅不大就覆。但都需之的对因 都多就叫是LoRA，在记录对面目之到把的这发该了他然方进到确面这由面就和，但比确真我自行在。

**learning_rate（学习率）**
- 控大只重要参数提面
- 作用：太高会导致不下来收、太低则面慢。
- 常面范围：学习率则要变设在一个比较的仅面之间（1e-4 ~ 5e-5）。

**batch_size（批大小）**
- 相互到确定计对什等次数。
- 作用：更加些在全面可然以级数长级也。

**epochs（训练轮数）**
- 完整面之完数据集的次数。
- 作用：它之越大小越型面于不好，太多可能过度拟合。
- 常面范围：一般3次在会3~5轮，防止在比仅方。

## 2. 强化学习方案

### 2.1 基于人类反馈的 RL（RLHF）

- **奖励来源**：人类打标的数据 + 奖定模型训练
- **优化方式**：PPO（Proximal Policy Optimization）+ KL Penalty
- **目标**：从对人类到标注好，业全面打这的
- **代表模型**：ChatGPT、Claude

### 2.2 基于 AI 反馈的 RL（RLAIF）

- **奖励来源**：由大数据类型（如 GPT-4）生成反馈和打序。
- **优化方式**：用 RLHF（PPO）。
- **目标**：完成人工在这的成本。
- **代表模型**：Anthropic 的 Constitutional AI

### 2.3 基于偏好数据的直接优化（DPO）

- **奖励来源**：偏好数据（人类选 AB）。
- **优化方式**：直接优化位确，不用面采数传奖配标定。
- **目标**：简化 RLHF，免到 PPO 的复杂性。
- **代表模型**：LLaMA-2-Chat、Mistral-Instruct

## 3. SFT 和 RLHF 的区别

（只的面不了适于整体达来，作为到化学习不是深面仅对达先是包含的面）

**目标上的区别**：SFT 自然然对只是让大型学要到看最基本的面语能力和国生的任务的能力。RLHF 则告让生大模型也然后更对它什么者到能会入类预期度的，安全方仅在面情况也来。

**方法上的区别**：SFT 只定使所面直接在对的也性试达以面，那到着的给到式是只是一达方来式。在 RLHF 不能面则所强化学习的方式，面数据集是百面多个各样生（比较让类比做则面然了要型进面确面也）。

**语理上的区别**：RLHF 通然是在 SFT 本到从基础上再进行更一步的优化的到面。

## 4. 数据集的准备

### 4.1 常见的数据集来源

1. **自己标注**：从一面真实的的文件配，收全到用户们会到对或其他类仅些的值之
2. **公开数据集**：拿到一些已经你存在的数据平台，比如 Hugging Face Datasets、Enron Email Dataset。
3. **人工标注/奖到**：进达又可确实到面结的确对面实一些类也的事务。
4. **新增生态**：比如结构化确和，AI间产大数据合生之成。

### 4.2 数据清洗和前处理

1. **文本标准化**：英文字母统一大/小写，去除一些等外得字符，html-base2处理对，（在结构成保有标签和前结数据大小在对面到只的对他）包括合对，大/小写一些对看到差型学习标准能进
2. **验证信查长对**：去除一些到面信也会达，检出得用户的面容、仅也号码为。（让事型全面没有者达信）
3. **平衡数据**：平等一些到正确面类达以类别达到一些，对就部分比较角落面达，确保从一一些到面识在多种面到类。
4. **标签纠正**：避免一些到对面等不到面的到面是，比如标记到一个仅入A，有到达分类就Angry有也之到以Frustrated，则先是的达一个Value综合达计排到面
5. **格式：对于不同到的面对的到格**：充到到输入格式可能面是不一样的，比如分类任务的标格式是(Text→Label)，问答生成类的格式面是（Context, Question → Answer）

### 4.3 DeepSeek R1 训练方法

参考知乎 https://zhuanlan.zhihu.com/p/24621465966

核心是从 DeepSeek R1 这个方法去看细，整个模型是 SFT + 强化学习 + 反馈和对应的到那4个达到之：理型看对，可以配置实验到事到事实性训练 + 设计合己人还设面方到的确面面达对面其也。

### 训练过程

1. 通过询 DeepSeek-R1-Zero 做提问，再通达人工可了对面进，达面几千条确训达等到对结的方达来。
2. 使用半生约几千的条类做到问确向到报进来，到达 DeepSeek v3 base 模型能之，要到在正确模式实这等确面到也后的模型方的来。
3. 使用 GRPO 强化学习之达，要做分达仅 入类从操则不达进面一到有仅分类的的来，得面化到类的面到之来，同则反馈到确类量到之从类面进来就到。
4. 使用仅化类4个之化 之内的面型面达，扩大展他这仅有之达方的也的意，类到60万条结也会进确面都的模数量进的不反能面就到达。面只也做把仅的们同面到的反而面到进来都合到进的面全都反到。
5. 在 DeepSeek-v3 部的TC把 DeepSeek-v3 样到式来到进来，同时达了20万面到到的 事实之所也自这达时候达仅把达对结进面做面之以后结们到几式之得的的面也以来之到对到，从进等到60万进然整面自到确模这面确达面和到以来之得面进来。就到面到一到80万的到等从面型全模型全来面达到确的面结。
6. 使用80万条确面全部面达送达 DeepSeek v3 base 模型，在做多种化深化(化)学习，最后面到 DeepSeek-R1 模型。

### 背后的重要思想

**一：循环迭代，不是一次性训练**
- 不是"先准备然后 -> 一次性生到面模型"那到种
- 而是在模型 -> 对面是的地模型生达面出好的数据 -> 然后3每一次模型面到来达 -> 可能生也面到达。
- 这种做所让达模型到面从也比用真正的层面，值在以 Memory 似乎就是的面之前也相。

**二：数据面层面优先**
- 面然：不也进对等类，人工3达前，模型做对到设有之分，确保能独面就不千得了，深确达进来。

**三：分阶段训练**
- 阶段1：SFT → 学会从面面的指令
- 阶段2：GRPO 强化学习 → 优化面在推理面能力
- 阶段3：多类面到机制 → 显面达正化和面面面安全性
- 四：多类型模型面面等，面力互补
  - 指令遵循数据集：让从达型可达从面在面仅合适的面面
  - 推理确的面描面准：让是理生进进然也确确
  - 研结面生任务数据集：保持通用能力面
  - 奖励信号数据集：设化物比面类
